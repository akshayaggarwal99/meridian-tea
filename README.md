# Meridian Tea Company (fictional)

Meridian Tea Company is a fictional tea shop. This site exists so the Aquarius demo account for its owner, Nadia, has a website that matches her demo mailbox. Nothing here is for sale, and the phone number is in the reserved 555 range.

Two gaps are deliberate, because they match the demo mailbox and give the crew something real to catch:

- Autumn Sky oolong is listed as in stock, though the shop's mail says it sold out.
- First Light White, which the shop does carry, is not listed.
